CONECTAR GITHUB

Solo se hace una vez por dispositivo

Tu tienda está en GitHub Pages, que no tiene servidor propio. Para que los cambios lleguen a tus clientes, el panel los guarda directamente en tu repositorio usando un token de acceso.

¿Cómo creo el token? (2 minutos)
  1. Abre github.com/settings/personal-access-tokens/new
  2. Token name: Panel tienda · Expiration: 1 año (o la que prefieras)
  3. Repository access: Only select repositories → elige el repositorio de tu tienda
  4. Permissions → Repository permissions → Contents: Read and write
  5. Clic en Generate token, cópialo y pégalo aquí

El token se guarda solo en este navegador. No lo compartas con nadie.
